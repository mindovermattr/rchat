# Задачи для развития чат-приложения

## 1. Авторизация и профиль пользователя
- Реализовать страницу логина/регистрации (реальные данные, не моки)
- Хранить токен (JWT) и восстанавливать сессию при перезагрузке
- Страница профиля: редактирование имени, аватара, статуса

## 2. WebSocket-чат в реальном времени
- Подключить WebSocket (socket.io) к NestJS-серверу
- Реалтайм-доставка сообщений всем участникам чата
- Индикатор набора текста (typing indicator)
- Онлайн-статусы пользователей в реальном времени

## 3. Редактирование и удаление сообщений
- Контекстное меню (правый клик / long tap) на своём сообщении
- Режим редактирования: сообщение подсвечивается, открывается редактор с existing HTML
- Удаление с подтверждением через модальное окно (`@mantine/modals` уже установлен)

## 4. Загрузка файлов и изображений
- Кнопка прикрепления файла в `MessageInput`
- Превью изображений перед отправкой
- Отображение вложений в чате (картинки inline, файлы — ссылки)
- Хранение на сервере (локально или S3)

## 5. Поиск по сообщениям
- Расширить поиск в sidebar: не только по названию чата, но и по содержимому сообщений
- Подсветка совпадений в результатах
- Переход к конкретному сообщению по клику на результат

## 6. Реакции на сообщения (Reactions)
- Эмодзи-реакции под сообщениями (👍 ❤️ 😂 и т.д.)
- Подсчёт реакций, отображение уникальных эмодзи с количеством
- Тултипы с именами пользователей, поставивших реакцию

## 7. Групповые чаты: создание и управление
- Создание нового группового чата с выбором участников
- Модальное окно выбора пользователей из списка
- Переименование чата, добавление/удаление участников
- Отображение аватаров отправителя в каждом сообщении (уже частично реализовано)

## 8. Уведомления и звуки
- Браузерные уведомления (Notification API) при новом сообщении
- Звуковое оповещение (разные звуки для личных и групповых чатов)
- Счётчик непрочитанных в заголовке вкладки (`document.title`)

## 9. Кэширование и офлайн-режим
- Хранение истории чатов в `localStorage` / IndexedDB
- Отображение кэшированных данных при отсутствии сети
- Очередь отправки сообщений (отправлено offline → доставлено при восстановлении связи)
- Индикатор статуса сети (online/offline)

## 10. Эндпоинты и REST API на NestJS
- Реализовать CRUD-эндпоинты для пользователей, чатов и сообщений
- Валидация данных (class-validator + DTO)
- Подключить PostgreSQL (TypeORM / Prisma)
- Swagger-документация автоматически
